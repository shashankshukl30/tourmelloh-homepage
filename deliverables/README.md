# Tourmelloh stationery

- **Tourmelloh-Letterhead.pdf**: A4 letterhead for printing or for PDF letters.
- **Tourmelloh-Letterhead.docx**: the same letterhead in Word. Type in the body; the header and footer stay in place on every page.
- **Tourmelloh-Email-Signature.html**: the email signature.
  - Gmail: open the file in Chrome, select the signature (Ctrl+A), copy, then Gmail → Settings → See all settings → General → Signature → paste → Save.
  - The logo loads from tourmelloh.com, so it appears once the website is live on that domain.
- Previews: the two PNG files.

Rebuild after any change: `node deliverables/source/build.cjs` then `python deliverables/source/build_docx.py`.
